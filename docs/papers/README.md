# Literature

Third-party paper PDFs are intentionally **not vendored** in this repository.

The project keeps reading notes, experimental takeaways, and canonical external links in [`../paper_notes.md`](../paper_notes.md). This keeps the repository lightweight and avoids redistributing papers that are already available from their authors or publishers.

Core references covered by the notes include:

- ReAct — reasoning and action interleaving
- Self-Refine — iterative self-feedback and refinement
- Reflexion — verbal reinforcement / reflection memory
- CRITIC — tool-interactive critique and correction
- Large Language Models Cannot Self-Correct Reasoning Yet — limitations of intrinsic self-correction
- ExpeL — experiential learning for agents
- Self-Consistency — multi-sample reasoning and voting
- Chain-of-Verification — verification-oriented generation

For exact citations and links, see [`docs/paper_notes.md`](../paper_notes.md).
